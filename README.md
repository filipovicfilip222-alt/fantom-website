# Fantom — Arhitektura Digitalnih Sistema

High-performance, visually stunning website for a premium digital agency built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Fonts:** Inter

## 🎨 Features

- **Ultra-Modern Dark Theme** - Deep blacks, neon accents, glassmorphism
- **Smooth Animations** - Powered by Framer Motion
- **Responsive Design** - Mobile-first approach
- **Custom Cursor** - Enhanced user experience
- **Optimized Performance** - Fast loading times
- **Serbian Language** - All content in Serbian (Latin script)

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🌐 Development

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
